# Phase 08 — UI, Onboarding, Rewards, and Accessibility

## Objective
Make the MVP understandable and pleasant without developer guidance.

## Tasks

- Implement event-driven first-session onboarding and persistence.
- Complete responsive HUD/navigation for touch, controller, and desktop.
- Add daily reward, playtime reward, and simple code redemption with server validation.
- Add settings for reduced motion, camera shake, music, SFX, effects quality, and UI scale.
- Add loading/profile failure screens and reconnect-safe UI state.
- Prevent modal/pop-up stacking and shop interruptions during onboarding.
- Conduct an unaided new-user playtest and record confusion points.

## Acceptance criteria

- A fresh tester can melt, upgrade, unlock a tool, and understand the next goal without verbal help.
- Rewards cannot be claimed early, twice, or via client time manipulation.
- UI remains usable on a small phone and controller.
- Rarity and affordance are understandable without color alone.
