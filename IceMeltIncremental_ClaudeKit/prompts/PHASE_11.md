# Phase 11 — Release Candidate and Launch Package

## Objective
Produce a release candidate plus the exact owner checklist for safe publication and measurement.

## Tasks

- Execute every checklist in `docs/09_QA_RELEASE.md` and record evidence.
- Validate Test vs Production IDs, data store names, analytics, and debug flags.
- Review every external asset and remove hidden/unnecessary scripts.
- Tune onboarding/economy against actual recorded playtest times.
- Create final placeholder icon/thumbnail compositions in Studio if final art is not ready, and create an owner asset replacement list.
- Draft game title, description, update notes, controls, and first-week monitoring plan.
- Build `.rbxlx`, tag/commit a release candidate, and document rollback steps.

## Acceptance criteria

- No known data-loss, receipt-duplication, or critical exploit issue.
- 30-minute multiplayer soak has no red errors.
- New-user onboarding succeeds unaided.
- Production configuration is explicit and test data remains isolated.
- Owner receives a concise publish checklist and KPI review plan.
