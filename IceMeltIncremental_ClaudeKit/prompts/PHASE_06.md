# Phase 06 — Thaw Prestige

## Objective
Implement one meaningful reset layer that awards Embers and accelerates future runs without corrupting retained progression.

## Tasks

- Implement server calculation for eligibility, preview, award, and confirmation token/version.
- Build Thaw UI explaining exactly what resets and what remains.
- Reset Heat, run upgrades, tools, zones, and run counters as documented.
- Retain Embers, Thaws, discoveries, settings, rewards, and purchases.
- Apply Ember production multiplier and a small permanent node set if documented.
- Log Thaw progression analytics.
- Test disconnect/rejoin around confirmation and save.

## Acceptance criteria

- First Thaw can be reached in roughly 20–30 minutes during a representative playtest or tuning change is documented.
- Replayed/stale confirmation cannot duplicate Embers.
- Reset fields and retained fields exactly match documentation.
- Player resumes a noticeably faster second run.
